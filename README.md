# مساعد الطالب الذكي العُماني — قاعدة المناهج

**المرحلة الحالية:** Sprint 01 — إنشاء فهرس وصفي للمناهج العُمانية للصفوف 1–12.

هذه النسخة لا تحتوي على نصوص كتب، ولا تقوم بتنزيلها. هدفها تسجيل المصادر وتهيئة نموذج قاعدة البيانات قبل الاستيراد القانوني والتحقق البشري.

## المكونات
- `curriculum.py`: أوامر تهيئة SQLite وإدخال بيانات وصفية لكتاب بعد التحقق.
- `sources.csv`: ستة مصادر للجرد الأولي؛ ليست قائمة كتب مكتملة.
- `grade_inventory.csv`: تغطية الصفوف الاثني عشر؛ جميع الكتب ما زالت قيد الجرد.
- `test_curriculum.py`: اختبارات تلقائية.
- `.github/workflows/tests.yml`: تشغيل اختبارات Python في GitHub Actions.

## التشغيل
يتطلب Python 3.10+ دون مكتبات خارجية.

```bash
python curriculum.py init
python curriculum.py report
python -m unittest -v test_curriculum.py
```

لإضافة بيانات كتاب **بعد توثيقها** أنشئ ملف JSON (المثال افتراضي):
```json
{"grade":5,"subject":"المادة بعد التحقق","title":"العنوان بعد التحقق","source_id":"SRC001","semester":1}
```

```bash
python curriculum.py add-book --json verified_book.json
```

## الحدود
- عدد الكتب والمقاطع المستوردة حاليًا: **صفر**.
- لا توجد إضافة WordPress أو مساعد دردشة منشور.
- حقوق المصادر **غير مفترضة**؛ وتبقى حالة الترخيص `unknown` والمراجعة `pending`.
- **لا ترفع ملفات الكتب أو قاعدة SQLite المحلية أو مفاتيح API إلى المستودع العام.**

## خطوات التطوير التالية
جرد الكتب والطبعات بدقة، والتحقق من الحقوق، ومراجعة عينة استخراج، ثم بناء البحث والاسترجاع الموثق وربط ووردبريس بصورة مستقلة.

المصدر الرئيسي: https://ict.moe.gov.om/book/ (جميع الحقوق للجهة المالكة).

## Sprint 02 — جرد الأدلة الرسمية (قيد المراجعة)

أُضيف ملف `official_evidence.csv` الذي يحفظ **أربعة مراجع وصفية مرشحة** من دليل الطبعات الرسمي، تخص تقنية المعلومات للصفين 7 و8 والفصلين للصف 12. جميعها بحالة `needs_manual_review` وحقوق `unknown`، ولا تُعَدّ كتبًا مستوردة أو معتمدة.

- `python evidence.py` يفحص المعرفات والصفوف والروابط الرسمية وحالات المراجعة.
- `python -m unittest -v test_evidence.py` يختبر رفض الصفوف غير الصحيحة والروابط غير الرسمية والاعتماد دون اسم مراجع.
- لا تنقل السجلات إلى جدول الكتب المعتمد إلا بعد مراجعة صفحات الدليل وأذونات الاستخدام.

**تنبيه حقوقي:** صفحات دليل الطبعات تشير إلى قيود متعلقة بإعادة نسخ الكتب وتخزينها. توثيق عنوان الكتاب والرابط لا يمنح تلقائياً إذناً باستخراج محتواه أو إعادة نشره.

## Sprint 03 — اكتشاف صفحات الكتب الرسمية واستيراد البيانات الوصفية

أُضيف `discovered_books.csv` ويحتوي خمسة عناوين **مكتشفة من صفحات بموقع الوزارة** في تقنية المعلومات للصفوف 7 و8 و10 و11 و12 (الفصل الأول). هذه البيانات تصف صفحات عامة فقط ولا تمثل ترخيصاً بنسخ أو معالجة المحتوى. تفاصيل الإصدارات تحتاج مراجعة بشرية، ولم تُستورد أي نصوص.

الأوامر:

```bash
python discovery.py check
python discovery.py register
python curriculum.py report
python -m unittest -v test_discovery.py
```

`register` يدرج **البيانات الوصفية فقط** في قاعدة SQLite المحلية، مع ترك `rights_status=unknown` و`review_status=pending`، ويمكن تكراره دون تكرار الصفوف. لا ينشئ ملفات الكتب ولا ينزّلها.

ملاحظة تصحيحية: كان دليل 2025–2026 مستخدماً بالخطأ سابقاً لتسجيل سنتَي 2026–2027 في سجلي EV003 وEV004؛ صُححت السنة وفق عنوان الدليل، وبقيت السجلات غير معتمدة حتى المراجعة.

## Sprint 04 — مراجعة الكتب وضبط صلاحية المحتوى

أُضيفت أداة `review_workflow.py` وسجل قرارات `book_review_events` داخل SQLite. المراجعة تفصل بين **صحة البيانات الوصفية** وبين **إذن معالجة المحتوى**؛ ولا تمنح الحق باستخدام الكتب تلقائياً.

```bash
python discovery.py register
python review_workflow.py report
python -m unittest -v test_review_workflow.py
```

تتطلب قرارات المراجعة الخمسة حقولاً صريحة: معرف الكتاب، القرار، المراجع، رابط الدليل، والتعليل. القرارات الممكنة: `verify_metadata`، `reject_metadata`، `permit_content`، `restrict_content`. قرار `permit_content` لا يُستخدم إلا بعد توثيق إذن كتابي حقيقي من صاحب الحقوق وبعد تحقق بيانات الكتاب؛ وجود رابط عام ليس إثباتاً لهذا الإذن. لا يتم هنا تخزين نصوص الكتب أو رفعها أو إرسالها لمزوّد نماذج ذكاء اصطناعي.

## Sprint 05 — بحث محلي آمن في الفهرس

تتيح أداة `catalog_search.py` البحث في **البيانات الوصفية فقط** حسب الصف والمادة والعنوان والفصل، مع إظهار رابط المصدر وحالة المراجعة والحقوق بشكل منفصل. لا تُعرض نصوص الكتب ولا تُنشأ إجابات ذكاء اصطناعي.

```bash
python discovery.py register
python catalog_search.py --grade 7
python catalog_search.py --subject "تقنية المعلومات" --query "العاشر"
python -m unittest -v test_catalog_search.py
```

> حقل `content_available` لا يصبح `true` إلا إذا كانت بيانات الكتاب معتمدة، والحقوق موثقة، والاستخراج مكتملًا؛ ظهور رابط كتاب لا يحقق هذه الشروط. هذه النسخة لا تتصل بموقع WordPress.

## Sprint 06 — تقرير تغطية الفهرس دون ادعاء اكتمال المنهج

تتيح أداة `coverage_report.py` تقريراً محلياً للصفوف 1–12 يميز بين عدد الكتب المفهرسة، واعتماد البيانات الوصفية، وإذن المحتوى، وحالة الاستخراج، ويكشف نقص الروابط والسنة الدراسية والطبعة.

```bash
python discovery.py register
python coverage_report.py
python -m unittest -v test_coverage_report.py
```

**تنبيه:** الأعداد تصف سجلات محلية فقط، ولا تمثل نسبة اكتمال الكتب الرسمية؛ لا توجد حتى الآن قائمة مرجعية موثقة بالعدد المتوقع لكل صف. تقرير التغطية لا يستخرج محتوى الكتب ولا يجيز استخدامه.

## Sprint 07 — تدقيق اتساق البيانات الوصفية

أُضيف `metadata_audit.py` لتدقيق بيانات الكتب المحلية دون قراءة أو تعديل نصوصها. يكشف الروابط غير الآمنة، وعناوين الكتب المفقودة، وتعارض حالات مراجعة البيانات وحقوق المحتوى والاستخراج. لا تُفسّر أهلية الحالات بأنها إثبات لتوافر محتوى فعلي أو إذن قانوني مستقل.

```bash
python discovery.py register
python metadata_audit.py --strict
python -m unittest -v test_metadata_audit.py
```

التدقيق لا يراجع المستندات القانونية نفسها، ولا يغني عن المراجعة البشرية، ولا يمنح إذناً جديداً باستخدام الكتب.

## Sprint 08 — بوابة أهلية الاسترجاع الآمن

أُضيف `retrieval_gate.py` لإرجاع **معرفات المقاطع وأرقام الصفحات فقط** بعد تحقق جميع الشروط: اعتماد بيانات الكتاب، توثيق إذن معالجة المحتوى، اكتمال الاستخراج، وجود رابط HTTPS صالح، وجود سجل `permit_content` بدليل HTTPS لم يُلغَ بقرار تقييد لاحق، واعتماد المقطع نفسه. عند غياب أي شرط تعيد البوابة قائمة فارغة (fail closed).

```bash
python -m unittest -v test_retrieval_gate.py
python retrieval_gate.py --db curriculum.sqlite3 --book-id 1
```

**حدود الأداة:** لا تعيد نصوص الكتب ولا تجيز تنزيلها أو إرسالها إلى نموذج ذكاء اصطناعي. تعتمد على حالات وسجل مراجعة محلي؛ لا تتحقق بنفسها من أصالة وثيقة الإذن أو هوية المراجع. يلزم تحقق بشري مستقل قبل أي استخدام فعلي.

## Sprint 09 — جدول التنزيل والرفع اليدوي

أُضيف `manual_manifest.py` لإنشاء قالب CSV فارغ للكتب (بدون اختلاق عناوين أو تنزيل أي PDF). يُفتح الملف في Excel ويضم الصف والفصل والمادة ونوع الكتاب والرابط الرسمي وحالة التنزيل والرفع والمراجعة والحقوق.

```bash
python manual_manifest.py init --file manual_books_manifest.csv
python manual_manifest.py check --file manual_books_manifest.csv
python -m unittest -v test_manual_manifest.py
```

لا يستبدل `init` ملفاً موجوداً. يرفض `check` الصفوف غير الصحيحة والروابط غير الآمنة وحالة الرفع قبل التنزيل. ينبغي إدخال الصفوف بعد التحقق اليدوي من المصدر الرسمي، وعدم رفع الكتب إلى GitHub العام. وجود الملف في Google Drive لا يمنح إذناً لمعالجة نصوص الكتب؛ يلزم توثيق الحقوق بصورة مستقلة.

## Sprint 10 — تقرير تقدم جمع الكتب يدوياً

أُضيف `manifest_progress.py` لإنتاج ملخص لكل صف (1–12) وفصل (1–2)، مع عدد السجلات المدخلة، والكتب التي نُزّلت ورُفعت، والبيانات المعتمدة، وحالات الحقوق المصرح بها. يتوقف التقرير عند أي خطأ في ملف CSV بدلاً من إظهار أرقام مضللة. لا يُنشئ سجلات كتب ولا يقرأ ملفات PDF.

```bash
python manual_manifest.py init --file manual_books_manifest.csv
python manifest_progress.py --file manual_books_manifest.csv
python manifest_progress.py --file manual_books_manifest.csv --json
python -m unittest -v test_manifest_progress.py
```

**مهم:** الأرقام تعكس السجلات المدخلة فقط؛ العدد الرسمي المتوقع لكل صف غير معروف، ولا يجوز تفسير الصفر على أنه عدم وجود كتب. حقوق المحتوى تحتاج إثباتاً مستقلاً قبل المعالجة.
