# مساعد الطالب الذكي العُماني — قاعدة المناهج

**المرحلة الحالية:** Sprint 01 — إنشاء فهرس وصفي للمناهج العُمانية للصفوف 1–12.

هذه النسخة لا تحتوي على نصوص كتب، ولا تقوم بتنزيلها. هدفها تسجيل المصادر وتهيئة نموذج قاعدة البيانات قبل الاستيراد القانوني والتحقق البشري.

## المكونات
- `curriculum.py`: أوامر تهيئة SQLite وإدخال بيانات وصفية لكتاب بعد التحقق.
- `sources.csv`: ستة مصادر للجرد الأولي؛ ليست قائمة كتب مكتملة.
- `grade_inventory.csv`: تغطية الصفوف الاثني عشر؛ جميع الكتب ما زالت قيد الجرد.
- `test_curriculum.py`: اختبارات تلقائية.
- `.github/workflows/tests.yml`: تشغيل اختبارات Python في GitHub Actions.

## التشغيل
يتطلب Python 3.10+ دون مكتبات خارجية.

```bash
python curriculum.py init
python curriculum.py report
python -m unittest -v test_curriculum.py
```

لإضافة بيانات كتاب **بعد توثيقها** أنشئ ملف JSON (المثال افتراضي):
```json
{"grade":5,"subject":"المادة بعد التحقق","title":"العنوان بعد التحقق","source_id":"SRC001","semester":1}
```

```bash
python curriculum.py add-book --json verified_book.json
```

## الحدود
- عدد الكتب والمقاطع المستوردة حاليًا: **صفر**.
- لا توجد إضافة WordPress أو مساعد دردشة منشور.
- حقوق المصادر **غير مفترضة**؛ وتبقى حالة الترخيص `unknown` والمراجعة `pending`.
- **لا ترفع ملفات الكتب أو قاعدة SQLite المحلية أو مفاتيح API إلى المستودع العام.**

## خطوات التطوير التالية
جرد الكتب والطبعات بدقة، والتحقق من الحقوق، ومراجعة عينة استخراج، ثم بناء البحث والاسترجاع الموثق وربط ووردبريس بصورة مستقلة.

المصدر الرئيسي: https://ict.moe.gov.om/book/ (جميع الحقوق للجهة المالكة).

## Sprint 02 — جرد الأدلة الرسمية (قيد المراجعة)

أُضيف ملف `official_evidence.csv` الذي يحفظ **أربعة مراجع وصفية مرشحة** من دليل الطبعات الرسمي، تخص تقنية المعلومات للصفين 7 و8 والفصلين للصف 12. جميعها بحالة `needs_manual_review` وحقوق `unknown`، ولا تُعَدّ كتبًا مستوردة أو معتمدة.

- `python evidence.py` يفحص المعرفات والصفوف والروابط الرسمية وحالات المراجعة.
- `python -m unittest -v test_evidence.py` يختبر رفض الصفوف غير الصحيحة والروابط غير الرسمية والاعتماد دون اسم مراجع.
- لا تنقل السجلات إلى جدول الكتب المعتمد إلا بعد مراجعة صفحات الدليل وأذونات الاستخدام.

**تنبيه حقوقي:** صفحات دليل الطبعات تشير إلى قيود متعلقة بإعادة نسخ الكتب وتخزينها. توثيق عنوان الكتاب والرابط لا يمنح تلقائياً إذناً باستخراج محتواه أو إعادة نشره.
